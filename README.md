# 📖 Интерактивная HTML5-книга «Его Высочество Юмор» / Борис Шварцман

Премиальный флипбук-просмотрщик: реалистичное перелистывание страниц
(StPageFlip), твёрдые обложки, динамические тени и изгиб страницы,
свайп, клик по краю, клавиатура, мягкий звук шелеста бумаги (Web Audio API),
адаптив (разворот на десктопе, одна страница на телефоне),
меню **«Содержание»** с переходом на любой раздел, затемнённый фотофон
позади книги и «магнитное» перелистывание при удержании уголка.

---

## 1. Как запустить (пошагово)

Проект полностью автономен: все пути относительные, библиотека лежит в `vendor/`.

### Вариант А — Windows (самый простой)
1. Дважды кликните **`start_server.bat`**.
2. Браузер откроется на `http://127.0.0.1:8000/index.html` автоматически.

### Вариант Б — Python вручную
```bat
cd /d "E:\2027\ШВАРТЦМАН САЙТ КНИГА\книга"
python -m http.server 8000
```
Затем откройте в браузере: <http://127.0.0.1:8000/index.html>

### Вариант В — Visual Studio Code
1. Откройте папку книги в VS Code.
2. Установите расширение **Live Server** (Ritwick Dey).
3. Правый клик по `index.html` → **Open with Live Server**.

### Вариант Г — Node.js
```bash
npx serve -l 8000
```

> ⚠️ **Почему нужен сервер:** при открытии через `file://` браузер блокирует
> `fetch(pages.json)` (CORS). Книга всё равно работает (есть резервный
> счётчик 248 страниц), но для полной функциональности используйте HTTP-сервер.

## 2. Структура проекта

```
книга/
├── index.html              ← точка входа
├── style.css               ← стили (фон, меню, центрирование, адаптив)
├── app.js                  ← логика: StPageFlip, подгрузка, звук, меню, магнит
├── convert_pdf.py          ← скрипт: PDF → WebP (170 dpi) + манифест
├── toc_check.py            ← скрипт: разбор «Содержания» из PDF → toc.json
├── start_server.bat        ← запуск локального сервера в один клик
├── Shvarzman_maket-FULL_web.pdf   ← исходный PDF (246 стр.)
├── vendor/
│   ├── page-flip.browser.js        ← StPageFlip 2.0.7 (с патчами, см. README-PATCH.md)
│   └── README-PATCH.md             ← описание внесённых правок
└── assets/
    ├── bg.webp                    ← затемнённый фотофон позади книги
    └── pages/
        ├── page-1.webp … page-248.webp ← 248 страниц, 870×1339 px, ~20,4 МБ
        ├── pages.json              ← манифест для предзагрузчика
        ├── toc.json                ← 52 пункта «Содержания» (со страниц 243–244)
        └── toc.js                  ← те же данные для меню (window.__TOC)
```

## 3. Подготовка ресурсов (если PDF изменился)

```bash
pip install pymupdf pillow
python convert_pdf.py     # страницы → WebP + pages.json
python toc_check.py       # «Содержание» → assets/pages/toc.json (+ toc.js)
```

Скрипт `convert_pdf.py`:
* рендерит все страницы PDF в **WebP**, 170 dpi, качество 82;
* приводит все страницы к **единому формату 870×1339** (обложки вписывает
  с обрезкой краёв, чтобы не было белых полос);
* **разрезает «двустраничные» страницы PDF** (2 и 245 — по пунктирной
  линии сгиба) на две половины → получается ровно **248 страниц**,
  поэтому первая и последняя страницы оказываются одиночными
  (работает `showCover: true`, как в настоящей книге);
* пишет `assets/pages/pages.json`.

Скрипт `toc_check.py`:
* вынимает «Содержание» с печатных страниц 238–239 (PDF 242–243) с координатами,
  склеивает многострочные пункты и группирует их по разделам;
* **сверяет каждый пункт с текстом целевой страницы** (все 52 пункта подтверждены);
* пишет `assets/pages/toc.json`; после этого данные нужно продублировать
  в `assets/pages/toc.js` (меню читает именно его — работает и без сети).

## 4. Функциональность (Premium UX)

| Возможность | Как реализовано |
|---|---|
| Разворот 2 страницы / 1 страница | `size:"stretch"`, ориентация выбирается по доступному месту (портрет при ширине блока < 520 px) |
| Твёрдые обложки | `showCover: true` + `data-density="hard"` на 1-й и 248-й страницах |
| Тени | `drawShadow: true`, `maxShadowOpacity: 0.5`, CSS-тени корешка и разворота |
| Свайп / перетаскивание | встроенные обработчики StPageFlip (мышь и палец) |
| Клик по краю страницы | зона 12 % ширины разворота (`app.js → hitTest`); углы страницы ведёт сама библиотека (сворачивание при наведении) |
| **«Магнитное» перелистывание** | удержание уголка 2 с (`CONFIG.magnetHold`) → медленный контролируемый переворот за 2,6 с (`CONFIG.magnetTime`); во время удержания — пульсирующее золотое кольцо у курсора |
| Клавиатура | `←` `→` `PageUp` `PageDown` `Пробел`, `Home`, `End`, `Esc` (закрыть меню) |
| Кнопки | ‹ › внизу экрана (блокируются на краях), звук, «во весь экран» |
| **Меню «Содержание»** | кнопка в верхней панели; 52 пункта по 4 разделам с печатными номерами, подсветка текущего пункта, переход на любую страницу; на телефоне — нижняя шторка |
| **Фон позади книги** | `assets/bg.webp` (затемнение + виньетка + зерно); подложка блока книги — плотная, непрозрачная, без контуров: при перевороте страницы не просвечивают |
| Звук | Web Audio API: мягкий шелест (широкая полоса, плавные фейды, срезанные высокие) + глухой хлопок; настройка хранится в localStorage |
| Подгрузка | окно ±10/20 страниц вокруг текущей + фоновая предзагрузка всего издания |
| Ссылка на страницу | адрес обновляется: `index.html#p123`, работает переход по ссылке |
| Прелоадер | прогресс-бар до загрузки первых 6 страниц + защитный таймер |

**Технология:** StPageFlip 2.0.7 (DOM + clip-path, а не примитивный `rotateY`),
с четырьмя патчами: три устраняют зависание книги в конце издания,
четвёртый возвращает корректное перелистывание **«назад» в портретном
(мобильном) режиме** (см. `vendor/README-PATCH.md`).

## 5. Настройка (app.js → объект `CONFIG`)

| Параметр | Значение | Назначение |
|---|---|---|
| `maxWidthPage` | 620 | предельная ширина одной страницы, px |
| `minWidthPage` | 260 | ниже удвоенного значения — режим одной страницы |
| `flippingTime` | 900 | длительность анимации, мс |
| `magnetHold` | 2000 | удержание уголка до «магнитного» переворота, мс |
| `magnetTime` | 2600 | длительность магнитного переворота, мс |
| `maxShadowOpacity` | 0.5 | плотность тени страницы |
| `nearAhead` / `nearBehind` | 20 / 10 | сколько страниц подгружать вокруг текущей |
| `edgeRatio` | 0.12 | ширина кликабельного края разворота |
| `preloadStart` | 6 | сколько страниц ждать до снятия прелоадера |

## 6. Проверено

* десктоп: разворот, обложка-одиночка, тени, корешок, счётчик «X–Y / 248»;
* переключение альбомная ⇄ портретная без «залипания»;
* клик по краю / по центру (центр не листает), свайп, `←` `→`, `Home`/`End`;
* **мобильный вид (390 px, портрет):** кнопка ‹, клик по левому краю,
  свайп справа налево и `←` — страницы листаются назад;
* **узкий экран (600 px, разворот):** верхняя панель без перекрытий;
* меню «Содержание»: 52 пункта, подсветка текущего, переходы;
* магнитный переворот: удержание уголка 2 с → медленный переворот одной страницы;
* прелоадер, подсказка, тумблер звука;
* консоль браузера — без ошибок.
